操作方法

WASD : カメラの移動（自由視点時）
E / Q : カメラの上昇 / 下降
左ドラッグ : 視点の回転（見回す）
Shift : 移動を3倍速に（自由視点時）
ホイール : ズーム（自由視点: 前後移動 / 3人称: 距離）
F / 1 / 3 : 自由 / 1人称 / 3人称視点
Space : 再生 / 一時停止
← / → : 5秒戻る / 進む
Tab : スコアボード表示
※ マップ(地形)データがない場合、灰色のブロックは表示されずプレイヤーのみが空中に表示されます。
